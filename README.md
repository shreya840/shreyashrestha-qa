WEB UI Testing for Katalon Demo Cura Healthcare and the Swag labs ,
I created automated tests for the Cura Healthcare website I did some manual testing and created some test cases before automation testing. I used Selenium WebDriver with Python to check different parts of the website, like logging in, viewing products, and the checkout process. This helped me learn how to use Selenium to test websites and ensure they work correctly. I used the following tools such as 
Python: The programming language used to write the test scripts.
Selenium WebDriver: The library used to interact with the web browser.
PyCharm: The Integrated Development Environment (IDE) is used to write and run Python scripts.
Microsoft Edge: The web browser used to execute the automated tests.
